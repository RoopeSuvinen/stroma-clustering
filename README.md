# Stroma Clustering
Course project investigating unsupervised clustering of colorectal cancer stromal tissue images.

## Goal
This project investigates whether different stromal tissue patterns in colorectal cancer histology images can be identified using unsupervised machine learning. Is it possible to group stromal regions in colorectal cancer histology images automatically into distinct morphological clusters using deep learning feature extraction and unsupervised clustering methods?

Want to find balance between great bias <-> great variance, underfitting <-> overfitting and poor accuracy <-> poor generalization.
Minimizing Bias^2 + Variance
